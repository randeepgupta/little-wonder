# Little Wonder

Little Wonder explores an affordable, screen-free conversational learning toy for young children that works fully offline. The first milestone is to evaluate small language models locally for useful, age-appropriate conversation.

This is an early research project. No model or device has been demonstrated to be safe for children, and the proposed costs, latency and hardware capabilities remain unverified targets.
